### Phase 1 — 计划核心（1 周）

**目标：** 登录后设置考试日 → 生成 70 天个性化计划 → 每天打卡 → 看进度。

**数据层（表已就绪，无需新迁移）：**

| 表 | 用途 |
| --- | --- |
| `user_settings` | 考试日 `exam_date`、每日单词目标 |
| `subjects` | 用户科目（政治 / 英语 / 高数一，可自定义增删） |
| `study_plans` | 每日每科任务（`plan_date`、`subject_id`、`task_type`、`is_completed`） |

**后端 API（在 `server/src/plan/` 新建模块）：**

| 接口 | 说明 |
| --- | --- |
| `POST /plan/init` | 传 `exam_date` + 科目权重 → 倒推 70 天生成 `study_plans`（幂等，先清旧计划） |
| `GET /plan/summary` | 剩余天数、当前第几天、总完成率、各科完成率 |
| `GET /plan/day/:dateOrDay` | 某天任务列表 |
| `PATCH /plan/:id/completion` | 打卡 / 取消打卡 |
| `GET|POST|PATCH|DELETE /subjects` | 科目管理（新模块已有代码，接线即可） |

**计划生成算法（放 `@shck/shared`）：**

- 70 天三段式：基础夯实（D1–20）→ 强化训练（D21–45）→ 冲刺/错题清零（D46–70）
- 每天每科 1 条任务，类型来自 `TASK_TYPES`（STUDY / REVIEW / PRACTICE / VOCABULARY）
- 支持按**科目权重**（如高数 40% / 英语 35% / 政治 25%）与**个人薄弱点**调整任务占比

**前端：**

- 保留登录页；Dashboard 改版为：倒计时 + 今日任务 + 打卡 + 进度条
- 新增「计划配置」页：考试日、科目、权重、薄弱点
- 新增「计划日历 / 按天」视图（可选）

**验收：** 注册 / 登录 → 配置考试日与科目 → 生成 70 天计划 → 逐日打卡 → 看板进度正确。
