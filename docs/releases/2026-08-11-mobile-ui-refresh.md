## 2. 今日学习页变更

- 按新 UI 稿重构页面排版、颜色、卡片、按钮和时间轴。
- 顶部突出距考试天数和下一项学习任务。
- 词汇任务标题读取后台每日目标，避免继续显示旧计划中的“新词 35”。
- 下一项任务卡展示开始时间、预计时长、剩余任务和剩余用时。
- 顶部箭头、任务、用时和调整提醒图标统一使用项目 Vant 图标，并按 UI 稿修正尺寸、角标与对齐。
- 延期任务继续支持查看、移至周末和撤销。
- 今日计划使用时间轴展示真实任务、科目、时长和完成状态。
- 本周安排继续读取桌面后台配置的工作日与周末学习容量。
- 所有任务入口、日期切换和现有计划 API 保持不变。
- 页面插画使用 CSS 图形完成，没有增加批量图片资源。

## 3. 我的页面变更

- 按新 UI 稿重构考生信息、考试倒计时、学习摘要、学习入口和只读设置区域。
- 今日学习时长、本周学习进度、单词数量和待复习错题全部读取现有 API 数据。
- 本周学习目标读取后台配置的每周可用时长，移动端不增加配置入口。
- 通知提醒与考试信息仅展示后台配置结果，不允许在移动端修改。
- 学习入口继续复用现有移动端路由；退出登录流程保持不变。
- 页面图标统一使用项目现有的 Ant Design 与 Vant 图标组件，并按 UI 稿补齐书本、气泡、角标和日历状态，不使用临时 Unicode 字符。

## 4. 知识检索页面变更

- 按新 UI 稿重构标题、搜索框、科目筛选、结果数量和知识卡片。
- 继续使用现有知识检索 API，支持关键词与科目组合查询。
- 每次查询默认展开第一条结果，其余结果可独立展开和收起。
- 知识正文继续支持 Markdown、代码、列表和 KaTeX 公式横向滚动。
- 结果总数使用 API 返回的 `total`，不再用当前分页列表长度代替。
- 搜索、箭头和收起图标统一使用项目现有 Ant Design 图标组件。

## 5. 词汇快速学习页面变更

- 按 UI-2 重构“英语词汇”总览、学习新词、小测验、错题重练和学习完成页面。
- 从“我的”进入 `/m/vocabulary` 时先展示本轮进度、剩余新词、到期复习、待重练词和上次学习位置。
- 从“今日学习”的词汇任务进入时携带 `autostart=1`，直接显示当前学习卡，不再闪过词汇总览页。
- 学习会话刷新后继续停留在当前词，退出会话才返回词汇总览；每次提交仍使用现有 API 保存进度。
- 新词页保留构词拆解、词族联想或常用搭配线索，并补充常用例句，不增加移动端配置入口。
- 小测验使用现有 `CHECK`、`RETRY` 和 `REVIEW` 阶段，答题后展示正确含义和例句；答错的新词会在本轮稍后再次出现。
- 词汇流程使用沉浸式布局，进入后隐藏移动端主导航，避免学习操作区与底部导航冲突。
- 图标统一使用项目已有 Ant Design 图标组件，不使用临时字符或手绘图标。
- 词汇总览按 UI-2 校准为单行三步骤、三个等宽剩余量卡片；“本轮安排”每行固定展示任务图标、目标数量和完成状态。
- 修正步骤箭头被圆形序号样式误命中的问题；步骤统一使用 UI-2 的蓝色编号体系，完成状态保留与主按钮一致的操作区高度。

## 6. 验收清单

- demo 账号能够正常打开 `/m/tasks`。
- 下一项任务与今日计划第一条未完成任务一致。
- 点击“开始学习”进入对应任务执行页。
- 点击时间轴中的任务能够进入任务执行页。
- 延期任务可以移至周末并撤销。
- 点击本周日期能够切换相应计划。
- 360px 及以上手机宽度不应出现横向滚动。
- Web 类型检查与生产构建必须通过。
- “我的”页面学习统计与接口返回一致，所有已有学习入口可正常打开。
- 通知提醒和考试信息在移动端不得出现编辑表单。
- 知识检索支持回车和“查找”按钮提交，科目筛选切换后立即刷新结果。
- 检索结果数量必须与 API 返回的总数一致，第一条结果默认展开。
- Markdown、列表和数学公式在 360px 及以上手机宽度下不得撑破卡片。
- 从“我的”点击背单词应进入词汇总览；从“今日学习”点击词汇任务应直接进入学习会话。
- 学习会话刷新后不得闪现词汇总览，当前服务端队列位置不得被重置。
- 完成首次学习、小测、错题重练后退出，总览中的数量和上次学习位置必须同步更新。
- 学习新词页必须展示核心含义、构词线索和例句；答题反馈必须展示正确含义。
- 词汇总览、单词卡、选项和底部操作区在 360px 及以上宽度不得溢出。

## 7. 生产部署

本阶段只有 Web 变更，不需要执行 Migration，也不需要 Seed。完成全部移动端页面后，统一执行：

```bash
pnpm --filter @shck/web lint
pnpm --filter @shck/web build
```

将新的 `packages/web/dist/` 上传生产服务器并重建 Web 镜像。API 与 MySQL 不需要因本阶段改动重启。

## 8. 回滚

只需恢复上一版本 Web 静态资源或 Web 镜像。没有数据库结构与数据回滚步骤。
