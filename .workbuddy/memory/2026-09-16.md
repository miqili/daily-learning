## 本地联调环境（重启后必看，省得白折腾）
本机**没有**跑 MySQL/Docker，`pnpm dev:server` 直接起会 `ECONNREFUSED 127.0.0.1:3306`。要连生产库：
```
cd <repo> && DB_HOST=8.218.204.8 DB_PORT=43306 DB_USERNAME=study_app \
  DB_PASSWORD=<见 MEMORY.md> DB_DATABASE=daily_learning pnpm dev:server
```
（`.env` 里的 DB_HOST/PORT 是 127.0.0.1:3306，会被环境变量覆盖；JWT_SECRET 仍取 `.env`。）

`/tmp/wb_token.txt` 里的 JWT 会过期（约 2h），过期后页面全部 401 → 进空态、`.wb-card` 永远等不到（表现为 playwright `wait_for_selector` 超时，很容易误判成"页面坏了"）。
**重签（无依赖，直接 HMAC）**：
```python
import base64,hmac,hashlib,json,time
b64=lambda b: base64.urlsafe_b64encode(b).rstrip(b'=')
h=b64(json.dumps({"alg":"HS256","typ":"JWT"},separators=(',',':')).encode())
now=int(time.time())
p=b64(json.dumps({"id":1,"username":"demo","role":"USER","iat":now,"exp":now+7200},separators=(',',':')).encode())
sig=b64(hmac.new(b'replace-with-a-long-random-secret',h+b'.'+p,hashlib.sha256).digest())
open('/tmp/wb_token.txt','w').write((h+b'.'+p+b'.'+sig).decode())
```
用户表是 `sys_users`（不是 users），现有人 `demo`(id=1) / `lyq`(id=4)。

**排查口诀**：`.wb-card` 等不到 → 先 `curl -H "Authorization: Bearer $(cat /tmp/wb_token.txt)" 127.0.0.1:3000/api/v1/papers`，401 就是令牌过期，别去改页面。

## 修 bug：折叠→展开时侧栏品牌块「字体漂移」（用户反馈）

**根因**：折叠态 `.brand-copy` 用 `display: none`，展开瞬间文字直接出现，而 `.shell` 的 `grid-template-columns` 还在做 0.24s 过渡。文字没有 `nowrap`，于是每帧在 68→196px 增长的窄容器里**重新换行/重排** —— 观感就是「字体漂移」。同类问题还在 `.nav-text`（clip-path 视觉隐藏 + `justify-content: center` 瞬间切换 → 图标跳位）与 `.sidebar-footer`（`display:none`）。

**修法（核心心法：折叠动画期间全程不切 display / justify，只收宽度）**
- 所有折叠时该消失的文字**一律 `<span>` 包裹 + `min-width:0; overflow:hidden; white-space:nowrap`**，用 flex 自然收缩宽度 + `opacity` 淡出；`nowrap` 是命门（否则仍会重排）。
- 折叠态**不再改 `padding-left`**：`.nav-link` / `.sidebar-toggle` 左右都保持 12px，`.brand` 两侧都保持 4px。这样展开/折叠图标**零位移**，同时折叠栏（内容区 44px）里 36px 品牌图标 + 4px×2 内边距 = 完美居中。
- 过渡属性补齐：`gap`、`padding`、`height`（分组标题）、`max-height`+`padding`+`opacity`（底部卡）都进 `transition`。`justify-content` 和 `display` **不可过渡**，所以一个都不能用。
- `.nav-section-label` 展开态显式给 `height:16px; line-height:16px`，折叠态才可能平滑收到 `height:1px` 的分隔线（`height:auto` 无法过渡）。
- `.sidebar-footer` 折叠态改用 `max-height:0 + padding:0 + opacity:0 + border-top-color:transparent`，配合 base 的 `overflow:hidden; max-height:240px`（实测内容 122px，各档都不裁）。

**定向验证方式（逐帧 rAF 采样，比截图靠谱）**：在页面里用 `requestAnimationFrame` 采样各帧的图标 `left`、文字 `getBoundingClientRect().height`，再统计「唯一值个数」——
- 图标 `left` 唯一值 = 1（0.00px 跳变）、主/副标题高度唯一值各 = 1 → 证明零位移 + 零重排。
- 修前：图标帧间跳变 1.67px；修后：0.00px。脚本 `/tmp/brand_reflow.py`。
- 想抓「过渡中间态」截图，用 CDP `Animation.setPlaybackRate(0.1)` 放慢 10 倍再截，否则 0.24s 的动画在截图开销下早就跑完了（第一版 120ms 采样抓到的已是终态）。

**验收脚本同步**：`/tmp/verify_sidebar.py` 中两条针对旧实现的断言已改（`nav-text` 由「offsetWidth<=1」改为「opacity=0 且被裁切且文字仍在」；「justifyContent=center」改为「图标左缘=24px 与展开态一致」），并新增 J 段（折叠/展开过渡逐帧无重排 + 图标零位移）。
